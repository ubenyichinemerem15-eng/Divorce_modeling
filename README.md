# Mathematical Modelling of Divorce in Marriage

## Overview
This project presents a mathematical study of divorce in marriage using a compartmental model approach. It investigates factors influencing divorce, their effects on marital stability, and possible remedies.

## Methodology
A five-compartment mathematical model was developed to describe the dynamics of marriage and divorce. The system of equations was analysed to determine equilibrium points and their stability.

## Analysis
The model includes:
- Disease-Free Equilibrium (DFE)
- Endemic Equilibrium Point (EEP)

Stability analysis was carried out using the Jacobian matrix method.
